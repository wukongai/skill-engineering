# Skill Engineering 1.1 Native Authoring 实施计划

状态：In Progress；NA-0 已完成

日期：2026-07-29

对应 Spec：[`2026-07-29-v1.1-native-authoring-spec.md`](../specs/2026-07-29-v1.1-native-authoring-spec.md)

## 计划目标

把创建主链路从“委托外部 Creator + 脚手架 fallback”升级为自包含的 Native Authoring Kernel：小白用户只安装 `skill-engineering`、只描述目标，即可在交互引导下一步步得到功能完整、工程架构优雅的 Skill，并在创建终点获得结构、内容、安全和工程化的评审与分数反馈。

治理边界：

- `2.0 Architecture Guardian Phase 1` 在 1.1 期间暂停，既有 Blueprint 工作不删除；
- 不新建第二套 Doctor 或评分模型，创建评审复用 Doctor v2 与 `quality-score-standard`；
- 阅读、注释、图谱能力不进 1.1，留在 `1.2.0`；
- 代码变更先在隔离候选完成；commit、push、tag、公开发布分别获得明确授权。

## NA-3：Content Completion Gate

### 工作

1. 新增随 Skill 交付的可移植检查器 `skills/skill-engineering/scripts/content_gate.py`（仅标准库，宿主有 Python 即可运行），实现 Spec “确定性阻断”全部条目（占位内容、空资源、通用 fallback 语句、断链引用、脚本缺失、frontmatter 基线、副作用无审批、复杂流程无失败处理、凭证泄漏）；
2. 无 Python 环境时的 Agent-native 等价检查清单写入 `references/content-completion-gate.md`；
3. 门禁接入 preview/apply：存在阻断项时不得 Apply，用户可见状态 `candidate_incomplete`；语义检查结果进入预览摘要，但不冒充真实行为效用；
4. Python CLI：`src/skill_engineering/scaffold.py` / `cli.py` 的旧 flag-based create fallback 标记 `scaffold_only`，输出不得出现“完整创建成功”；创建计划增加内容完整性状态字段，旧计划按 1.0 语义读取、不静默升级为 `content_complete`；
5. 测试先行：先观察新增门禁测试因缺少能力失败。

### 退出条件

- 占位符/空资源/通用套话/断链/凭证候选全部被阻断并有测试；`scaffold_only` 语义有回归测试；1.0 计划兼容读取通过。

## NA-4：创建评审与评分

### 工作

1. 创建写后流程固定为：结构 postflight → Content Completion Gate → Doctor v2 评审（复用 `scripts/doctor_skill.py` / `src/skill_engineering/skill_doctor.py` 与 `references/quality-score-standard.md`，不新建评分模型）；
2. `stages/doctor/INSTRUCTIONS.md` 增加创建场景入口；`references/doctor-standard.md` 补充创建评审用法；
3. 用户可见反馈模板：结论先行（能否开始使用、分数和等级、最需要关注的一两个维度）；存在 FAIL 或 SEC 命中时创建状态不得高于 `candidate_incomplete` 并给出唯一修复入口；未做真实任务试用时必须明示“尚未验证实际任务效果”；规则命中和修复建议折叠进“技术详情”；
4. 落地用户可见状态机：`needs_discovery` / `candidate_incomplete` / `candidate_ready` / `created_untried` / `validated` / `needs_improvement`，写入 journey 与输出契约；
5. 创建完成时生成简易自动化测试入口（结构/内容门禁复跑、声明脚本真实执行、一个与用户需求一致的样例任务），用户一句话或一条命令即可复跑；测试通过作为 `validated` 的证据之一，失败进入 `needs_improvement`，不得包装成成功；
6. 测试守护：评分不得被描述为效果分或业务价值分，不得跨 Skill 排名；SEC 命中必须阻断。

### 退出条件

- 创建终点包含评审分数反馈的 Case 级证据；评分边界表述有测试守护。

### 工作

### 退出条件

## 风险与恢复

- 宿主无 Python：Kernel 与 Gate 必须提供 Agent-native 等价路径，portable checker 只使用标准库；
- 评分被误读为效果分：所有输出模板和测试强制“结构就绪度 + 尚未验证实际效果”表述；
- 旧 fallback 误报完成：`scaffold_only` 标记加输出文案测试；
- 范围蔓延：阅读、注释、图谱请求一律进 BACKLOG `1.2.0`，不进本 Sprint；
- 发布失败：保留 `v1.0.0` tag 与可撤销 release record。
