# Sprint：v1.1 Native Authoring

状态：In Progress

日期：2026-07-29 起

对应：[`Spec`](../specs/2026-07-29-v1.1-native-authoring-spec.md)、[`Plan`](../plans/2026-07-29-v1.1-native-authoring-plan.md)、[`ADR 0008`](../adr/0008-native-authoring-kernel.md)、[`ADR 0009`](../adr/0009-codex-canonical-release-gate.md)

## 目标

把创建主链路升级为自包含的 Native Authoring Kernel：普通用户只安装 `skill-engineering`，即可在交互引导下一步步得到任务专属、内容完整、工程架构优雅的 Skill，并在创建终点获得评审分数和简易自动化测试入口；不再依赖官方 `skill-creator`、宿主专用作者 Skill 或独立 Python CLI 完成核心创建。

`2.0 Architecture Guardian Phase 1` 在本 Sprint 期间暂停，既有 Blueprint 工作保留不删除。

## 进入范围

- Authoring Brief 契约与 journey 持久化；
- 原生完整候选生成（替换 skill-creator delegate 路径）；
- Content Completion Gate（portable checker + Agent-native 等价清单）；
- 创建评审与评分（复用 Doctor v2）、创建后简易自动化测试入口；
- 用户可见状态机：`needs_discovery` → `candidate_incomplete` → `candidate_ready` → `created_untried` → `validated` / `needs_improvement`；
- 宿主适配契约（Codex、Claude Code、Hermes、Pi、Kimi CLI）；
- 1.0 CLI/JSON/contract 兼容与 `scaffold_only` 降级语义；
- Case A–F 验收证据与文档同步。

## 不进入范围

- 创建后 README 注释文档、Guided Tour、Skill Graph（`1.2.0`）；
- 云端服务、模型 Provider、托管平台；
- 自动 Global 安装；
- 2.0 Architecture Guardian 新能力。

## 风险

- 宿主无 Python：Kernel 与 Gate 必须有 Agent-native 等价路径，checker 只使用标准库；
- 评分被误读为效果分：输出模板与测试强制“结构就绪度”表述；
- 旧 fallback 误报完成：`scaffold_only` 标记与文案测试；
- 范围蔓延：阅读、注释、图谱一律进 BACKLOG `1.2.0`。
